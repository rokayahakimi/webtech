## 2. Selectors lezen

Welke elementen raakt elke selector? Eén zin per selector.

- a. `header nav ul li a`: Deze selector selecteert alle links in een lijst binnen de navigatie in de header.
- b. `article > p`: Deze selector selecteert alle paragrafen die rechtstreeks kind zijn van een article.
- c. `.uren li:nth-child(3)`: Deze selector selecteert het derde lijstitem binnen een element met de class uren.
- d. `h2 ~ p`: Deze selector selecteert alle paragrafen die na een h2 komen en dezelfde ouder hebben.
- e. `.rassen li:first-child`: Deze selector selecteert elk eerste lijstitem van zijn ouder binnen een element met de class rassen.
